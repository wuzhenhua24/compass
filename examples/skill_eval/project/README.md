# sales-data

The workspace the agent is dropped into. `data/q3.csv` is regional revenue by
quarter; everything the example's prompts ask for is built from it.

Deliberately almost empty: this example measures *how the agent worked* — did
the skill load, did it use the script the skill bundles, what did the run cost
— not whether the prose it wrote is any good. Judging the report itself is a
correctness grader, which is user code (see the README one level up).
